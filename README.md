# Module-end-Assignement-E-learning-Platform-Purchases-using-MySQL

1. elearning_sales_analysis.sql
   Complete MySQL 8.0+ script: database, tables, sample inserts, join exploration,
   and analytical queries Q1-Q5.
2. elearning_sales_summary_report.docx
   One-page summary report based on the included dataset.

How to run:
1. Open MySQL Workbench and connect to your MySQL server.
2. Open elearning_sales_analysis.sql.
3. Execute the full script from top to bottom.
4. Run individual SELECT statements again as needed to inspect each result set.

Notes:
- The script drops and recreates the database named elearning_sales.
- Currency values are represented in illustrative USD amounts.
- Sample dates and names are fictional.
- The report's findings are calculated from the eight purchase rows.
